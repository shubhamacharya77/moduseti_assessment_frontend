👉 [**MODUS System Documentation & Architecture**](https://github.com/shubhamacharya77/moduseti_assessment_backend)

---

## 📌 Features

- 🖥️ **Split-Screen Executive Chat (`/chat`)**: 50/50 split layout featuring natural language message stream on the Left and dynamic Recharts visualizer / PDF Fact Inspector on the Right.
- 📊 **Dynamic Visualizations**: Live interactive Area Line Charts, Product Category Bar Charts, and Regional/Segment Pie Charts.
- 📄 **PDF Fact Inspector**: Interactive citation cards allowing C-suite leaders to inspect exact page numbers and document excerpts supporting AI recommendations.
- 🎨 **Dark Glassmorphism Design System**: Tailored dark-mode UI with sleek indigo accents, custom scrollbars, and quick-prompt chips.
- ⚡ **Auto-Scroll & Fast State**: Auto-scrolling chat history with clear-chat controls and loading states powered by React Query.

## 🚀 Getting Started

### 1. Installation
```bash
cd moduseti_assessment_frontend
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
* Application running at: `http://localhost:3000`
* Split-screen AI Chat running at: `http://localhost:3000/chat`
